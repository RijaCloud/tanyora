# SEO Cutover

## Before the switch

1. Keep pre-production explicitly non-public:

```env
DEPLOYMENT_ENV=preproduction
APP_BASE_URL=https://pre-prod.2424.mg
NEXT_PUBLIC_SITE_URL=https://pre-prod.2424.mg
```

`pre-prod.2424.mg/robots.txt` must disallow all crawling, its pages must return `noindex, nofollow`, and `/sitemap.xml` must return `404`.

2. On the approved production release only, set all three values together:

```env
DEPLOYMENT_ENV=production
APP_BASE_URL=https://www.2424.mg
NEXT_PUBLIC_SITE_URL=https://www.2424.mg
```

The frontend refuses an incorrectly declared production origin. Any undeclared environment remains `noindex` by default.

3. Export the legacy Yoast inventory:

```bash
pnpm seo:inventory
```

The generated `reports/seo/legacy-url-inventory.json` is intentionally ignored by Git. Keep it with the release evidence and verify every public legacy URL either resolves in Next or remains available from the legacy origin.


## Nginx canonical host

Apply this redirect before the Next virtual host. It preserves both path and query string.

```nginx
server {
    listen 80;
    listen [::]:80;
    server_name 2424.mg;
    return 301 https://www.2424.mg$request_uri;
}

server {
    listen 443 ssl http2;
    listen [::]:443 ssl http2;
    server_name 2424.mg;
    # Reuse the valid certificate for 2424.mg here.
    return 301 https://www.2424.mg$request_uri;
}
```

The `www` host proxies to Next. `/sitemap.xml` is the sitemap index generated by Next; do not proxy it to WordPress or Yoast.

## After the switch

1. Verify `https://www.2424.mg/robots.txt` declares only `https://www.2424.mg/sitemap.xml`.
2. Validate the sitemap index and all child sitemaps, then submit only the canonical sitemap to Google Search Console.
3. Keep the legacy WordPress origin available until the inventory has no unmapped indexable URLs.
4. Remove references to `trust.php` and `godsend.php`; they are not valid sitemap sources.

## Cookie consent

The frontend CMP stores a versioned first-party cookie for 180 days. AdSense, GAM and custom advertiser scripts are blocked until the visitor accepts the advertising category. Image campaigns hosted by 2424 remain available without third-party requests. The footer exposes `/politique-de-confidentialite` and `Gérer mes cookies`.

## Privacy policy and RSS

On each WordPress environment, create or update the legal page, state the 180-day cookie retention and its categories (necessary, preferences, analytics, advertising), then select it in **Settings > Privacy**. The platform endpoint exposes only this published page to Next, which renders it at `/politique-de-confidentialite`; no visitor is redirected to the legacy site.

`/feed/` is the canonical RSS feed for published editorial content. The frontend declares it in the document head. `/comments/feed/` permanently redirects to `/actualites` because public editorial comments are not available in Next.
